# M3 — Context manager, compaction, handoff, memory monitor

Status: **done** (2026-10-19), with the gaps listed below. Verified in this container (Linux host); nothing
here has run on a phone yet.

## What shipped

| Area | Package / path | Highlights |
|---|---|---|
| Escalation ladder | `packages/sherpa_core/lib/src/context` | Window-scaled thresholds (prune → clear inputs → compact → truncate → handoff recommendation → hard stop); pinned set; append-only segment rules for providers with preserved reasoning; overlays are reversible and never touch the transcript |
| Compaction | `sherpa_core` (`compaction.dart`, `summary_harvest.dart`) | Summary schema v2 with deterministic fields (constraints, paths, handles, completed side effects) carried forward; side-effect ledger that only believes trusted sources' annotations; extractive and model-written strategies |
| Token accounting | `sherpa_core` (`token_estimator.dart`), `sherpa_inference` | Calibrated estimator that counts nested tool-result parts (resources, media); exact engine counts for on-device chats (`EngineTokenCounter`, warmed off the UI isolate) |
| Handoff | `sherpa_core/lib/src/handoff`, `app/lib/features/context/handoff` | Bundle v1 with secret scrubbing (incl. JSON-shaped secrets, masked tool arguments), `sanitized()` and a builder self-check so every bundle parses; review screen, continue on this or another model, share/save, QR (gzip + base64url, size-gated); import from file, text or camera with size and decompression limits; imported content is untrusted |
| Inspector | `app/lib/features/context` | Budget breakdown against the thresholds, every item in the next request with markers and exact text, change list with diffs and Undo (dependent summaries undone together), Compact now |
| Memory monitor | `packages/sherpa_platform` | Android trim levels, `MemoryInfo`, Android 17 limiter, thermal; iOS memory warnings, dispatch pressure, `os_proc_available_memory`; feeds the runner (pause on critical) and the on-device lifecycle |
| Privacy dashboard | `app/lib/features/context/data`, `settings/privacy_screen.dart` | Export of all chats as a scrubbed JSON archive (secret values masked wherever they appear); delete all data (chats, providers, keys, preferences, downloaded models, KV prefixes) |

## How to verify

```sh
cd packages/sherpa_core && dart test        # ladder, compaction, handoff property tests
cd app && flutter test test/features/context
```

## Known gaps

- **Not verified on devices:** memory signals, camera QR scanning on iOS, share sheets.
- **Summaries:** extractive unless the chat runs on-device or the user opts in to model-written summaries for
  remote providers. Small-model summary fidelity is not yet measured on devices (L4 eval runs on the host).
- **Inspector counts** are labelled "Estimated" for remote providers; they can differ slightly from the
  runner's calibrated numbers.
- **Export** is built in memory; very large histories may be slow.
- **Handoff bundles** carry no MCP server connections yet.
