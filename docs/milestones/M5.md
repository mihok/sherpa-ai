# M5 — MCP Apps host, elicitation, sampling

Status: **done** (2026-10-19), with the gaps listed below. The shell page's security properties are
proven in Chromium; nothing ran in an Android WebView or WKWebView.

## What shipped

| Area | Package / path | Highlights |
|---|---|---|
| WebView plugin | `packages/sherpa_webview` | Own plugin (no `addJavascriptInterface`): shell page at a never-resolving https origin, server UI in a `sandbox="allow-scripts"` srcdoc iframe with an opaque origin, CSP applied twice (inherited and injected), no network unless the user consents to the server's declared domains; Android bridge injected only into the shell origin, per-server profile, network blocked; iOS non-persistent store, private content world, content rules |
| Apps bridge | `sherpa_webview/lib/src/bridge.dart` | Protocol order enforced, app-only tool visibility, approvals as tainted, confirmed `ui/message` and `ui/open-link`, size and rate limits, teardown |
| App integration | `app/lib/features/apps` | `McpAppMessageView` with text fallback, view pool (at most 3 live WebViews, off-screen views suspended, fullscreen), per-server network consent bound to the resource hash, revoke closes live views |
| Elicitation | `app/lib/services/mcp/input`, `app/lib/features/mcp/input` | Native forms for every schema type, server text framed as untrusted, secret-looking fields refused; URL mode shows the full URL, site and reason and opens only after confirmation in Custom Tabs / SFSafariViewController |
| Sampling | same | Off by default per server (not even declared); ask / allowed-in-chat; approval sheet with messages, model and token estimate; answer reviewed before it is returned; token and rate limits; no tools, no `includeContext`; local models at background priority |
| Queue | same | Requests attributed to their chat (`McpCallOrigin`), banner and inline cards, never a surprise pop-up, 5-minute polite timeout, redacted per-server history |

## How to verify

```sh
cd packages/sherpa_webview && flutter test && test/web/run.sh   # Dart + Chromium security suite
cd app && flutter test test/features/apps test/features/mcp test/services/mcp
```

## Known gaps

- **WebRTC** is not covered by CSP: a nested frame inside an app still has `RTCPeerConnection` (STUN/TURN
  could leak small amounts of data and the device IP).
- **Unverified WebView behaviour:** WebKit's handling of `frame-src 'none'` for the srcdoc child and of
  content rules for `about:` frames; Android origin-rule matching for the `.invalid` host and whether
  `blockNetworkLoads` also blocks WebSockets.
- **Not supported:** permissions for apps, `ui/download-file`, app-provided tools, `'unsafe-eval'` and blob
  workers (WebGL-style apps break), `frameDomains`.
- **Sampling:** "allow for this chat" lasts until restart; `includeContext` and tools can't be granted.
- No public-suffix list for consented domains; DNS rebinding of a consented domain is not prevented.
