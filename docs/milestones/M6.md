# M6 — Polish, accessibility, background execution, perf budgets, evals

Status: **done** (2026-10-19), with the gaps listed below. Verified in this container; nothing here has
run on a phone, and CI has not run (see "CI" below).

## What shipped

| Area | Path | Highlights |
|---|---|---|
| Background execution | `app/lib/services/background`, `packages/sherpa_platform` | One lease covers every running chat, begun while Sherpa is visible: Android foreground service (`shortService` for a reply, `specialUse` for agent runs), iOS `beginBackgroundTask` / `BGContinuedProcessingTask`. Runs that can't continue in the background (on-device GPU on iPhone, Gemini Nano) pause and say so; on expiry runs checkpoint and offer Continue; a content-free "Reply ready" notification; a notifications-permission card with a rationale; "Keep working in the background" setting |
| Accessibility | `app/lib/design/widgets/a11y.dart`, `app/test/a11y` | Widget-test audit of every screen at phone and tablet size, 1× and 2× text and dark mode: tap targets, labels, contrast (pixel and exact), overflow, heading order; RTL and reduced-motion checks; source rules (no hard-coded left/right, headings through `Heading`). Details: [M6-accessibility.md](M6-accessibility.md) |
| Evals | `packages/sherpa_evals` | L0 durability/approvals/rug-pull/carry-forward, L1 parser corpus, L2 BFCL-style subset, L3 long-horizon state tasks, L4 compaction fidelity, with gates and baselines. Runs scripted in CI, against a real local model on the host, or a remote provider |
| Perf budgets | `bench/`, `tools/perf_gate.dart` | Host benchmarks (Markdown streaming, context prepare, SSE, tool router, handoff, engine TTFT/decode) gated against `linux-ci` baselines with medians, sample minimums and absolute tolerance floors; `perf-rebaseline` label; frame-timing benchmark in `app/integration_test` with device-class placeholders and an opt-in emulator job |
| Diagnostics | `app/lib/features/diagnostics` | Settings › About › Export diagnostics: an allowlisted, scrubbed bundle (versions, device, engine, providers and MCP servers by host only, counts, error types), previewed in full before sharing; in-memory error ring |
| Composer | `app/lib/features/chat` | Photos (downscaled per provider, EXIF/GPS stripped), camera, text files, PDFs where the model reads them, dictation with on-device recognition preferred; links open after a confirm sheet |
| Content types | `sherpa_providers`, `sherpa_inference`, `native/engine` | PDF input for OpenAI Chat/Responses (gated per server); on-device vision through engine ABI 1.1 (mtmd, image KV caching by content hash) |

## What the evals found and fixed

The suites were run before their findings were fixed, so each fix is measured:

| Finding | Before | After |
|---|---|---|
| Completed side effects repeated after compaction (L4) | 42 duplicates, task success 75% | 0 duplicates, 100% |
| Handles losing what they identify after compaction (L4) | 45 re-lookups | 0 |
| Ambiguous tool arguments executed (duplicate keys, leaked template tokens) (L1) | false repair 15.1% | 0% |
| Identical non-idempotent calls in one reply both ran (L3, Qwen3-0.6B) | 2 notes created | 1 |

## CI

`.github/workflows/ci.yml` defines analyze + pure-Dart tests, Flutter tests, the Android build with the
16 KB gate, the iOS no-codesign build, evals, perf, the MCP Apps Chromium security suite and an opt-in
frame bench. **None of it has run**: every run on this repository fails within seconds because the GitHub
account's Actions are locked for billing. Every number in these notes comes from local runs in this
container. The first real CI run (and the first macOS build of the Swift code) is still ahead.

## How to verify

```sh
tools/test_all.sh                                          # analyze + every package and the app
cd packages/sherpa_evals && dart run sherpa_evals:eval --suite all --model scripted
(cd packages/sherpa_evals && dart run sherpa_evals:bench --samples 5 --out ../../build/bench)
dart run tools/perf_gate.dart --results build/bench --baselines bench/baselines/linux-ci
packages/sherpa_webview/test/web/run.sh                    # Chromium security suite
```
